At least one project reports the game in-game and under player control for 30 minutes or more without a crash, at 20 frames per second or better on some PC.

What the estimate rests on

  • One project went from nothing public to loading the game world in a day. XCL went from its first frame to the menus in about five hours.
  • XCL took lighter retail games from first boot to playable in a day or two. No project has done that with a game of this size.
  • The next gate is a picture of the world. One project is inside it, with a title card and then a dark scene at 0.5 to 1.8 seconds a frame. Two more code bases load the world and stop at its first frame, one on shader compiling and one on a graphics hang.
  • Risks: takedowns, a blocker nobody has hit yet, and low frame rates in the game itself. On 18 November GitHub published Take-Two takedown notices against unofficial GTA V ports and their forks, including ports that needed the user's own game files. Two GTA VI projects went offline on 23 November; no published notice names either.
  • One project's own README expects longer than this page does: at least a few weeks.

Method and limits

  • Playable builds

    None exist. Any download that claims to be GTA VI for PC is fake, and fake builds carrying malware have circulated since August.

  • The build

    These projects work from a leaked Xbox build. Rockstar has not released or announced a PC version. This page does not link to the leak or explain how to get or run it.

  • Sources

    Each project's public repository and open pull requests and, where marked, its chat. Project names link to those repositories to credit the work.

  • Stage claims

    Every stage is the project's own claim, and most are unverified. The menus are reported by several separate builds.

  • Crash reports

    By one project's notes, the game's crash reporter sends data to an outside server each time it crashes.

  • Who compiles it

    An AI assistant (Claude), automatically, about every 15 minutes. It can be wrong.

  • Affiliation

    None with Rockstar Games, Take-Two Interactive, Microsoft or any project listed.
