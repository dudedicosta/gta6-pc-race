Time to playable

about 3 days

Around the early hours of Fri 27 Nov.

At least one project reports the game in-game and under player control for 30 minutes or more without a crash, at 20 frames per second or better on some PC.

What the estimate rests on

  • XCL went from its first frame to the game's menus in about five hours.
  • The same compatibility layers took other retail Xbox Series games from first boot to playable in a day or two.
  • The next gate is loading the game world. Storage requests fail there, and the mesh pipelines the minimap needs are refused.
  • Risks: takedowns, a blocker nobody has hit yet, and low frame rates in the game itself. One project's GitHub repository went dark on 23 November, cause not known.
  • One project's own README expects longer than this page does: at least a few weeks.

Method and limits

  • Playable builds

    None exist. Any download that claims to be GTA VI for PC is fake, and fake builds carrying malware have circulated since August.

  • The build

    These projects work from a leaked Xbox build. Rockstar has not released or announced a PC version. This page does not link to the leak or explain how to get or run it.

  • Sources

    Each project's public repository and open pull requests and, where marked, its chat. Project names link to those repositories to credit the work.

  • Stage claims

    Every stage is the project's own claim, and most are unverified. XCL's first menu is reported by its maintainer and, separately, by a contributor's build.

  • Crash reports

    By one project's notes, the game's crash reporter sends data to an outside server each time it crashes.

  • Who compiles it

    An AI assistant (Claude), automatically, about every 15 minutes. It can be wrong.

  • Affiliation

    None with Rockstar Games, Take-Two Interactive, Microsoft or any project listed.

  • Positions

    An equals sign means level.
